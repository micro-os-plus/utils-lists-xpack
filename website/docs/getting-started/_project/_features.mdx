## Features and benefits

The key characteristics of **µOS++ Intrusive Lists** are as follows:

- List links are directly embedded within the payload objects, eliminating
  the need for separate link-node objects and dynamic memory allocations.
- Objects can belong to multiple lists simultaneously by maintaining a
  distinct pair of pointers for each list.
- Standard C++ iterators are provided, ensuring seamless integration with
  standard C++ algorithms.
- Performance is enhanced by eliminating the overhead of memory allocation
  and deallocation operations.
