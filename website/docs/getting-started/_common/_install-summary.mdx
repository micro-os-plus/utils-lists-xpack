## Install

The source code library can be installed either automatically via **xpm**
or manually. Manual installation can be performed by copying the necessary
files directly into the target project or by linking the entire project as
a Git submodule.

Comprehensive instructions for installing the
µOS++ Intrusive Lists
are available in the [Installation Guide](/docs/install/).
