## Build & integration info

The project is written in C++, and it is expected to be used in C++ projects.

The source code has been compiled natively with **GCC** and **LLVM/Clang**,
and cross-compiled on embedded **Arm** and **RISC-V** targets,
ensuring it is free from warnings.

To facilitate the integration of this library into user projects,
pre-made **CMake** and **meson** configuration files are provided
(see below).

For other build systems, please refer to the details provided below.

### Include folders

The following folders should be passed to the compiler during the build:

- `include`

The header files to be included in user projects are:

```cpp
#include <micro-os-plus/utils-lists.h>
```

### Source files

The source files to be added to user projects are:

- `src/lists.cpp`

### Preprocessor definitions

There are several preprocessor definitions used to configure the build:

- `MICRO_OS_PLUS_INCLUDE_CONFIG_H` - to include `<micro-os-plus/config.h>` 
(Note: deprecated in favour of `<micro-os-plus/project-config.h>`, included conditionally if it exists)
- `MICRO_OS_PLUS_TRACE` - to include and enable to implement the trace calls
- `MICRO_OS_PLUS_UTILS_LISTS_TRACE_ENABLED` - to trace some calls, like `clear()`,
  `insert()`, `link()`, `unlink()`
- `MICRO_OS_PLUS_UTILS_LISTS_TRACE_CONSTRUCTOR_ENABLED` - to trace constructors and
  destructors

The recommended way to pass the `MICRO_OS_PLUS_TRACE` macro and 
garantee it is seen in the whole project is via the 
compiler command line options, as `-DMICRO_OS_PLUS_TRACE`.

The recommended way to define the `utils-lists` specific macros is to use a 
separate header file,`micro-os-plus/utils/lists-defines.h`, and define the 
macros there (uncomment the desired lines).

```c title="micro-os-plus/utils/lists-defines.h"
#ifndef MICRO_OS_PLUS_UTILS_LISTS_DEFINES_H_
#define MICRO_OS_PLUS_UTILS_LISTS_DEFINES_H_

// Display trace messages in lists when TRACE is enabled.
// #define MICRO_OS_PLUS_UTILS_LISTS_TRACE_ENABLED

// Display trace messages in lists constructors and descriptors when TRACE is enabled.
// #define MICRO_OS_PLUS_UTILS_LISTS_TRACE_CONSTRUCTORS_ENABLED

#endif // MICRO_OS_PLUS_UTILS_LISTS_DEFINES_H_
```

For xCDL enabled projects, this file is automatically generated.

The `cdlSettings` to enable them are:

```jsonc title="xcdl-project.jsonc"
    "cdlConfigurations": {
      //
      "<name>": {
        ...
        "cdlSettings": {
          ...
          "micro-os-plus.utils.lists.trace": true,
          "micro-os-plus.utils.lists.trace.constructors": true
        }
      },
      ...
    }
```

### Compiler options

The following options must be passed to the compiler and linker:

- `-std=c++20` or higher for C++ sources

### Dependencies

The library has the following dependencies:

- `@micro-os-plus/diag-trace` - the **µOS++** `trace::printf()` tracing
  infrastructure (optional, used only if `MICRO_OS_PLUS_UTILS_LISTS_TRACE_ENABLED*`
  are defined)
