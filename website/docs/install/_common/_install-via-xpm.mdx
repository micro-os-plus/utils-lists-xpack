### Install via xpm

The next step is to install the
**utils-lists** package into the project.

The command to install the **latest** available version of **utils-lists** is:

<CodeBlock language="sh"> {
`xpm install @micro-os-plus/utils-lists@latest --verbose
`} </CodeBlock>


To install a **specific version**, specify it explicitly:

<CodeBlock language="sh"> {
`xpm install @micro-os-plus/utils-lists@4.0.0 --verbose
`} </CodeBlock>
